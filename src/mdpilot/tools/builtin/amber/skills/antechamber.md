# antechamber — Small Molecule Parameterization

## When to Use

Use antechamber **BEFORE** tleap when the system contains ligands or non-standard residues that are not in the standard AMBER force fields. antechamber assigns GAFF2 atom types, calculates partial charges, and converts between molecular file formats.

## Execution Environment

- **Node:** lab03 (local subprocess)
- **Exec path:** `$AMBERHOME/bin/antechamber`
- **Timeout:** default 300s (5 minutes)
- **Auto-runs parmchk2** when `run_parmchk=True` to generate `.frcmod` for missing parameters

## Workflow Position

```
pdb4amber (clean PDB)
    |
    v
antechamber (parameterize ligand → .mol2 + .frcmod)
    |
    v
tleap (load ligand params + build system)
    |
    v
pmemd_cuda (run MD)
```

## Charge Method Selection

| Method | Flag | Speed | Accuracy | When to Use |
|---|---|---|---|---|
| AM1-BCC | `-c bcc` | Fast (~0.1 min for 50 atoms) | Good (~RESP quality) | **Default, recommended for most cases** |
| RESP | `-c resp` | Slow (requires Gaussian/GAMESS) | Highest | Publication-quality; requires external QC software |
| Gasteiger | `-c gas` | Fastest | Lowest | Quick screening; very large molecule libraries |

**Always use `-c bcc` unless you have a specific reason to use RESP.**

## Atom Type Assignment

Always use GAFF2 (`-at gaff2`) unless legacy compatibility with older GAFF is required:

```
-at gaff2    # General AMBER Force Field 2 (recommended)
-at gaff     # Legacy GAFF (only for backward compatibility)
-at sybyl    # SYBYL atom types (for format conversion only)
```

## Output Files

antechamber produces two files that tleap needs:

1. **`.mol2`** — Tripos mol2 format with charges and atom types. Loaded in tleap with `loadMol2` or via `loadamberprep` (from `.prepc`)
2. **`.frcmod`** — Force field modifications file with missing dihedral/bond/angle parameters (generated by parmchk2). Loaded in tleap with `loadamberparams`

## Example Commands

### Basic: SDF to mol2 with AM1-BCC charges and GAFF2 types

```bash
antechamber -i ligand.sdf -fi sdf -o ligand.mol2 -fo mol2 -c bcc -nc 0 -at gaff2
parmchk2 -i ligand.mol2 -f mol2 -o ligand.frcmod
```

### From PDB with net charge -1

```bash
antechamber -i ligand.pdb -fi pdb -o ligand.mol2 -fo mol2 -c bcc -nc -1 -at gaff2
parmchk2 -i ligand.mol2 -f mol2 -o ligand.frcmod
```

### From SMILES string

```bash
antechamber -i "CC(=O)OC1=CC=CC=C1C(=O)O" -fi smi -o aspirin.mol2 -fo mol2 -c bcc -nc 0 -at gaff2
parmchk2 -i aspirin.mol2 -f mol2 -o aspirin.frcmod
```

### RESP charges (requires Gaussian)

```bash
antechamber -i ligand.mol2 -fi mol2 -o ligand_resp.mol2 -fo mol2 -c resp -nc 0 -at gaff2
```

## Parameters

| Parameter | Type | Description |
|---|---|---|
| `input_file` | str | Path to input molecular file |
| `input_format` | str | Input format: `mol2`, `sdf`, `pdb`, `smi` (SMILES) |
| `output_file` | str | Path to output mol2 file |
| `output_format` | str | Output format (default: `mol2`) |
| `charge_method` | str | Charge method: `bcc` (default), `resp`, `gas` |
| `net_charge` | int | Net molecular charge (default: 0) |
| `atom_type` | str | Atom type: `gaff2` (default), `gaff`, `sybyl` |
| `run_parmchk` | bool | Auto-run parmchk2 to generate `.frcmod` (default: True) |
| `workdir` | str | Working directory |
| `timeout` | int | Timeout in seconds (default 300) |

## Common Errors

| Error | Cause | Fix |
|---|---|---|
| "charge method not available" | AMBERHOME not set or SQM not found | Verify AMBERHOME environment variable points to valid Amber installation |
| "ATOM TYPE MISSING" after parmchk2 | Rare parameter not covered by GAFF2 | Manually edit `.frcmod` to add missing parameters; check AMBER parameter database |
| Input file not found | Incorrect file path | Verify input file exists in working directory |
| "Cannot determine bond type" | Ambiguous aromatic/saturate bonding in input | Use `-dr no` to disable bond type detection; provide mol2 with explicit bond orders |
| SQM failure during charge calculation | Molecular geometry too distorted | Optimize geometry first (e.g., with `obminimize` from OpenBabel); check for 3D coordinates |
| "Multiplicity not consistent" | Net charge incompatible with electron count | Verify `net_charge` parameter matches the molecule's actual charge state |
